# Scope Statement  
## InsightCare Analytics

**Version**: 1.0

---

### 1. In-Scope

**KPI & Requirements Work**
- Discovery of current reports and pain points
- Definition of Phase 1 KPIs with business owners
- Calculation rules, data sources, refresh frequency, and owners
- Prioritization (Must / Should / Could)

**Dashboards (Phase 1)**
- Executive Overview Dashboard
- Patient Flow & Capacity Dashboard (ED + Inpatient)
- Workforce / Staffing Overview (high-level)
- Quality & Safety Snapshot (selected indicators)
- Revenue Cycle / Financial Snapshot (selected indicators)

**Delivery Considerations**
- Power BI semantic model principles
- Role-based access concepts
- Validation and acceptance approach
- Basic documentation (KPI dictionary, user guides outline)

---

### 2. Out-of-Scope (Phase 1)

- Predictive models or AI-driven alerts
- Real-time device / bedside streaming
- Full replacement of all departmental Excel reports
- Regulatory submission reporting systems
- Advanced statistical analysis workspaces
- Mobile-native custom apps (responsive Power BI is in scope)

---

### 3. Key Deliverables

1. Project Charter & Business Case  
2. Stakeholder Analysis  
3. KPI Dictionary & Prioritization  
4. Metric Calculation Rules  
5. Business & Dashboard Requirements  
6. User Stories + Acceptance Criteria  
7. Validation / UAT Scenarios  
8. Sample Data + Power BI Implementation Notes  
9. Traceability Matrix & Risk Register  

---

### 4. Acceptance Criteria (Project Level)

- All Phase 1 Must-have KPIs have agreed definitions and owners
- Dashboards pass data validation against trusted source reconciliations
- Key user groups accept usability and content in UAT
- Role-based access demonstrated
- Documentation handed over for ongoing governance
