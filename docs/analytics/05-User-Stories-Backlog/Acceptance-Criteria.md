# Acceptance Criteria Reference  
## InsightCare Analytics

Detailed criteria are embedded in User Stories. Cross-cutting themes:

- Every dashboard shows “Data as of” timestamp
- KPI values use definitions from the signed-off KPI Dictionary
- Conditional formatting against targets is applied on key cards
- Filters (Date, Site/Facility where relevant) function correctly
- Role-based access prevents unauthorized viewing
- Validation scenarios pass within agreed tolerance before go-live
- Users can locate metric definitions without leaving the analytics experience (or via clear link)
