# User Stories  
## InsightCare Analytics

**Version**: 1.0

---

### Epic 1: Executive Visibility

**US-EX-01** – View Institutional Performance at a Glance  
**As an** Executive Leader  
**I want to** see a curated set of high-level KPIs and trends on one page  
**So that** I can quickly understand organizational performance and focus discussion  

**Acceptance Criteria**:
- KPI cards display current value, target comparison, and short trend
- “Data as of” timestamp is visible
- Filters for date range and site (if applicable) work correctly
- Definitions are accessible

**Priority**: Must | SP: 8

---

### Epic 2: Operational Flow & Capacity

**US-OP-01** – Monitor ED Performance Daily  
**As an** ED Director / Operations Manager  
**I want to** see ED wait time, length of stay, LWBS rate, and volume trends  
**So that** I can manage flow and escalate issues promptly  

**Acceptance Criteria**:
- Metrics match agreed definitions in KPI Dictionary
- Daily and trend views available
- Ability to filter by date
- Values reconcile to source within agreed tolerance during validation

**Priority**: Must | SP: 8

---

**US-OP-02** – Monitor Inpatient Capacity  
**As a** Bed Manager / Operations Lead  
**I want to** see occupancy, ALOS, and bed turnaround metrics  
**So that** I can optimize capacity and reduce delays  

**Priority**: Must | SP: 5

---

### Epic 3: Quality & Finance Snapshots

**US-QU-01** – Track Key Quality Indicators  
**As a** Quality Leader  
**I want to** view agreed quality KPIs with trends  
**So that** I can monitor performance and support improvement work  

**Priority**: Must | SP: 5

---

**US-FI-01** – Track Revenue Cycle Health  
**As a** Finance / RCM Leader  
**I want to** see Days in AR, Clean Claim Rate, and Denial Rate  
**So that** I can identify issues early and track improvement  

**Priority**: Must | SP: 5

---

### Epic 4: Trust, Governance & Usability

**US-GOV-01** – Access KPI Definitions  
**As any** Dashboard User  
**I want to** easily see how a metric is defined and who owns it  
**So that** I trust and correctly interpret the numbers  

**Priority**: Must | SP: 3

---

**US-SEC-01** – Role-Appropriate Access  
**As a** System Administrator  
**I want** users to only see dashboards and data appropriate to their role  
**So that** information is protected and relevant  

**Priority**: Must | SP: 5

---

**US-VAL-01** – Validate Dashboard Numbers  
**As a** Metric Owner / Analyst  
**I want to** compare dashboard values to source system extracts  
**So that** we can formally accept the dashboard as accurate  

**Priority**: Must | SP: 5
