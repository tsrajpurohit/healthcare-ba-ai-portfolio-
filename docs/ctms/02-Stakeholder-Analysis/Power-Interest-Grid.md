# Power-Interest Grid  
## TrialFlow CTMS

```
High Power
│
│  Keep Satisfied                     Manage Closely
│  • Principal Investigators          • Head of Clinical Operations
│  • Regulatory Affairs               • Clinical Operations Manager
│  • QA / Validation                  • Study Managers (key)
│  • IT / Clinical Systems
│
│──────────────────────────────────────────────────────────────
│
│  Monitor                            Keep Informed
│  • Pharmacovigilance                • CRAs / Monitors
│  • External Sponsors (varies)       • Site Coordinators
│                                     • Data Management
│
Low Power
         Low Interest ────────────────────────── High Interest
```

### Engagement Guidance
- **Manage Closely**: Steering decisions, prioritization, benefits tracking.
- **Keep Satisfied**: Regular updates, address concerns on burden and compliance.
- **Keep Informed**: Involve in process workshops, UAT, and feedback cycles — these users determine real-world success.
- **Monitor**: Periodic communication; escalate if influence or interest changes.
