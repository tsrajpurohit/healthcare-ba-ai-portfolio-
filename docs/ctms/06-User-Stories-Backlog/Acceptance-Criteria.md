# Acceptance Criteria Reference  
## TrialFlow CTMS

Detailed acceptance criteria are embedded with each User Story.  

### Cross-Cutting Themes
- Critical status changes (Site Activation, Subject Enrollment, Visit Completion) must be audit-logged
- Role-based permissions enforced on all create/update actions
- Enrollment cannot proceed without a recorded Informed Consent for the current protocol version
- Visit window calculations must correctly reflect protocol-defined windows relative to the reference visit
- Dashboards and lists must reflect near real-time status for the pilot data set
- Users must be able to complete core tasks with the training provided
