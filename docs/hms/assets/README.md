# Assets Folder

Place the following items here to make your portfolio richer:

### diagrams/
- Exported images of AS-IS / TO-BE process flows (from draw.io, Lucidchart, Bizagi, etc.)
- Power-Interest Grid visual
- Any wireframes or mock screens

### samples/
- Screenshots of Power BI / Tableau dashboards built from Sample-Metrics-Data.csv
- Sample invoice / registration slip mockups
- Any additional supporting documents

GitHub will render Mermaid diagrams directly from the Markdown files, so process models are already visual without extra images.
