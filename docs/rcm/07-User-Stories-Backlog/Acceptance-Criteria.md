# Acceptance Criteria Reference  
## MediClaim AI

Detailed Given-When-Then style criteria are embedded in the User Stories document.  

### Cross-Cutting Acceptance Themes for AI Features

- Every AI score/recommendation must display within agreed performance SLA
- Explanation (top factors) must be visible without extra navigation
- User must be able to accept, modify, or reject with mandatory reason on reject/modify
- All decisions logged with model version, user, timestamp
- Final coding and high-risk claim decisions remain with human users
- Workqueues default to AI priority but allow manual override and filtering
- Dashboards refresh with latest available data and support drill-down
