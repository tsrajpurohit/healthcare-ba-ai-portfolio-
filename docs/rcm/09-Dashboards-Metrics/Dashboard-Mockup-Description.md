# Dashboard Mockup Guidance  
## MediClaim AI Portfolio Demo

Use the provided `Sample-Metrics-Data.csv` to build compelling visuals.

### Suggested Executive Dashboard
- KPI Cards: Clean Claim Rate (trending up), Denial Rate (trending down), Days in AR, AI Acceptance Rate
- Line charts showing improvement over the sample period
- Bar chart of Denial Rate vs Clean Claim Rate
- Secondary page for AI-specific metrics (Acceptance Rate, Manual Touches reduction)

### Tips for Portfolio
- Add conditional formatting (green when targets met)
- Include a note on the dashboard about “Simulated post-AI improvement trajectory”
- Export screenshots into `assets/samples/`
- Optionally publish to Tableau Public or Power BI and link from README
